# 저는 결제하라고 나오면 닫아버립니다

AI 구독 결제창을 피해 5개월을 버티는 1인칭 CCTV 생존 공포 게임입니다. 전력 대신 토큰을 관리하며, 실시간 점수는 표시하지 않고 월말 정산 또는 게임 오버 인보이스에서만 점수를 계산합니다.

## 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

단일 파일 배포본을 만들려면:

```bash
npm run build
```

`index.html`을 파일로 열면 자동으로 `PLAY.html`로 이동합니다.

## 조작

- 마우스 또는 터치로 화면 버튼을 클릭합니다.
- 사무실 버튼: CCTV, 왼쪽/오른쪽 문, 왼쪽/오른쪽 라이트
- CCTV 버튼: 닫기, 이전/다음 카메라
- CCTV 화면의 지도 박스를 클릭하면 해당 카메라로 이동합니다.
- 키보드 단축키, 인게임 음소거 버튼, 인게임 모션 버튼은 없습니다.

## 규칙

- `1개월차`부터 `5개월차`까지 각 8분 55초, 총 535초를 버팁니다.
- HUD는 원작식 배치를 따릅니다. 우측 상단에는 현재 시간/월, 좌측 하단에는 남은 전력과 사용량 게이지를 보여줍니다.
- 토큰은 원작식 내부 999 카운터에서 시작해 99.9%로 표시됩니다.
- 매초 기본 사용량 1칸이 빠지고, CCTV/닫힌 문/켜진 라이트마다 사용량이 1칸씩 추가됩니다.
- 2개월차부터는 별도 passive drain이 붙습니다: 2개월차 6초마다 1칸, 3개월차 5초마다 1칸, 4개월차 4초마다 1칸, 5개월차 3초마다 1칸입니다.
- 토큰이 0%가 되면 CCTV, 문, 라이트가 실패하고 잠시 뒤 구독 블랙아웃 점프스케어가 발생할 수 있습니다.
- Gemini, Grok, ChatGPT는 현재 방을 CCTV로 보고 있으면 움직이지 않습니다.
- Claude는 커튼방에서 단계적으로 나오다 왼쪽 복도를 질주합니다. 질주 중에는 CCTV로 봐도 멈추지 않으므로 왼쪽 문 타이밍이 중요합니다.
- CCTV 지도에는 적 위치 점이나 아이콘이 없습니다. 실제 카메라 화면과 라이트로 확인해야 합니다.
- 라이트는 문 앞의 적을 확인하는 용도이며, Claude 질주는 라이트로 확인하지 않습니다.

## 카메라 방

- `CAM 1A` 무료 체험 무대
- `CAM 1B` 결제 대기실
- `CAM 1C` 무료 체험 커튼
- `CAM 2A` 왼쪽 복도
- `CAM 2B` 왼쪽 문 앞
- `CAM 3` 부품 창고
- `CAM 4A` 오른쪽 복도
- `CAM 4B` 오른쪽 문 앞
- `CAM 5` 백스테이지
- `CAM 6` 서버실

Gemini는 백스테이지와 부품 창고를 거쳐 왼쪽 복도로 접근합니다. ChatGPT도 백스테이지를 지나 서버실과 오른쪽 복도로 이동할 수 있습니다. Grok은 원작 Chica 역할처럼 서버실과 오른쪽 복도 중심으로 움직이고, Claude는 커튼방에서 시작해 왼쪽 복도 질주로 처리됩니다.

## 점수

월말 클리어 시 남은 토큰을 한 자리 소수로 저장합니다.

```text
monthTokenScore = round(tokens * 10) / 10
```

게임 오버 시:

```text
partialFailedMonthScore = round(tokens * survivedRatio * 10) / 10
finalScore = round((sum(clearedMonthTokenScores) + partialFailedMonthScore) * 10) / 10
```

5개월 완주 시:

```text
finalScore = round(sum(stageTokenResults) * 10) / 10
```

게임 오버 화면은 패배 원인별 구독 인보이스를 보여줍니다.

- Grok Doll: `Grok Heavy $300`
- ChatGPT Doll: `ChatGPT Pro $200`
- Claude Doll: `Claude Max $200`
- Gemini Doll: `Google AI Ultra $249.99`

## 자산 정책

- 모든 시각 자산은 `assets/generated/`의 로컬 PNG입니다.
- 로딩 화면은 ChatGPT/Gemini/Grok 세 인형이 서 있는 새 생성 PNG를 사용합니다.
- 타이틀 화면은 10~20초마다 한 번씩 기존 응시 이미지가 노이즈와 함께 짧게 튀어나옵니다.
- 모든 화면에는 얇은 CRT 노이즈와 스캔라인이 깔리고, CCTV와 타이틀 이스터에그에서는 더 강하게 보입니다.
- FNAF 자료는 카메라 구도와 CCTV 문법 참고용으로만 사용했고, 복사 이미지나 FNAF 원본 자산은 없습니다.
- SVG, 외부 이미지, 외부 오디오, 외부 폰트, CDN, 공식 로고, 실사 사진은 사용하지 않습니다.
- 오디오는 WebAudio로 즉석 생성합니다.

검증 항목:

- 1개월차도 매번 같은 루트로 고정되지 않음
- 보고 있는 CCTV 방의 Gemini/Grok/ChatGPT는 이동하지 않음
- Claude는 질주 중 CCTV로 봐도 계속 진행함
- 라이트가 문 앞 적을 드러내고 토큰을 소모함
- CCTV 지도에 적 위치 점이 없음
- active HUD에 실시간 점수가 없음
- 게임 오버 인보이스와 최종 클리어 화면에 토큰 점수가 표시됨
